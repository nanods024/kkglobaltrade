# KK Global Trade — Frontend

React + Vite + Tailwind CSS frontend for the KK Global Trade export website.
See the root [README.md](../README.md) for full setup, environment variables
and deployment instructions.

Quick start:

```bash
npm install
cp .env.example .env
npm run dev
```

The dev server proxies `/api` and `/uploads` to the backend (default
`http://localhost:5000`) — see `vite.config.js`.
